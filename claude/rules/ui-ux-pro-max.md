# UX & Token Architecture (ui-ux-pro-max)

Optional add-on to the Design Brief in `~/.claude/CLAUDE.md` section 2, for setups with the `ui-ux-pro-max` plugin. In the brief's precedence order it ranks below the brand reference and above `frontend-design` and Claude's own choices.

- **UX & Token Architecture** (`ui-ux-pro-max:ui-ux-pro-max`, `ui-ux-pro-max:design-system`): one `--design-system` run or a targeted domain search for UX flow, semantic color tokens, font pairings, spacing rhythm, and WCAG constraints.
- **Component styling** (`ui-ux-pro-max:ui-styling`): use alongside the aesthetic-direction step to settle component craft.
- **Hand-off**: `agy`'s local `ui-ux-pro-max` and `ui-styling` skills are for what the brief leaves open, such as stack-specific implementation guidance, and anything taken from them goes under `DECISIONS`.
